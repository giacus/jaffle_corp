# Open-Source Sanitization

The repo was created with these rules:

- Use only fictional jaffle-shop entities.
- Do not include real company names, internal system names, private schemas, personal names, emails, warehouse names, alert names, or production identifiers.
- Do not copy SQL from private projects.
- Use structural inspiration only: folder boundaries, config patterns, contracts, selectors, macros, and semantic layer organization.
- Keep seed data small, synthetic, and obviously fake.
- Scan for prohibited strings before publishing.
