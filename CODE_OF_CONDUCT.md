# Code of Conduct

`jaffle-corp` adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
That code applies anywhere people participate in or represent this project,
including issues, pull requests, reviews, discussions, and other public forums.

## Expected Behavior

Be respectful, specific, and constructive. Disagreement about architecture or
teaching choices is welcome; harassment, personal attacks, discrimination,
sexualized behavior, threats, publishing private information, and sustained
disruption are not.

Maintainers may edit or remove contributions, comments, or other participation
that violates these expectations. They may also warn, temporarily restrict, or
permanently exclude participants, following the Contributor Covenant's
enforcement guidelines and considering context and impact.

## Reporting

- For ordinary moderation concerns that contain no sensitive information, open
  a repository issue clearly marked as a conduct concern.
- For threats, harassment, exposed private information, or another concern that
  should not be public, use [GitHub's private abuse-reporting
  flow](https://support.github.com/contact/report-abuse).
- For a security vulnerability or accidentally committed secret, follow the
  private process in [SECURITY.md](SECURITY.md), not a public issue.

Reports will be handled as privately and promptly as the available information
allows. Maintainers will not retaliate against a good-faith reporter.
