# Attribution

`jaffle-corp` is inspired by dbt Labs' public
[`jaffle-shop`](https://github.com/dbt-labs/jaffle-shop) project.

The upstream project is a fictional restaurant sandbox used to teach and
demonstrate dbt. This repository keeps that recognizable fictional teaching
motif, then builds a separate advanced training fixture around it: a local
DuckDB-backed multi-project dbt monorepo with domain boundaries, project
dependencies, public contracts, protected implementation models, legacy
migration examples, synthetic seed data, Semantic Layer YAML, and direct
MetricFlow CLI workflows.

This repository is not a GitHub fork of `dbt-labs/jaffle-shop`, is not
affiliated with dbt Labs, and is not endorsed by dbt Labs. The name, data,
business entities, SQL models, docs, and exercises in this repository are
intended to be independently authored unless a file says otherwise.
